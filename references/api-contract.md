# Shared API contract

Historical endpoint notes: images reviewed 2026-09-08; meshes reviewed 2026-09-07. Verify official documentation before changing schemas or implementing a new phase: [images](https://doc.v2fun.art/zh/api/reference/images), [3D models](https://doc.v2fun.art/zh/api/reference/3d-models). These dates do not claim current remote revalidation.

Base URL is https://api.v2fun.art/api/v1 with Bearer authentication. Async requests use options.block=false and persist task_uuid. Status is QUEUED/PROCESSING/COMPLETED/FAILED; result contains asset URIs rather than a synchronous OpenAI image response. Mesh creation/query: /3d_models/meshes and /3d_models/meshes/{task_uuid}. Image edit guidance: /images/edits and /images/edits/{task_uuid}, with model, prompt, input_images, size and options. The generic runtime implements mesh submission, balance, status and download; image editing, retopology and standalone texturing require separate adapters.

Before POST, save SUBMITTING, input hashes, authorization and a budget reservation. Immediately save the returned task ID. Distinguish proven non-submission, proven rejection without creation, and uncertain outcomes. Missing IDs or HTTP errors alone do not prove no task exists. Uncertain outcomes must not be automatically resubmitted; reconcile the original task first. Queries/downloads reuse existing IDs and do not consume new-task reservations. Expired signed URLs require querying the original task, not regenerating.

One poller per task, normally at least 15 seconds between queries; after 429/5xx back off at least 120 seconds. Stop at terminal states. Keep polling inside the executor. Use the task's finite authorized plan and shared budget ledger; account limits may require fewer concurrent tasks. Do not reset budget history on recovery. Actual billing requires usage/billing evidence; balance deltas may include other activity.

Keep keys, signed links, prompts and encoded assets out of public packages. Save detailed responses locally; download matching asset_path/download_url entries without API credentials on the download request. Shared manifests have one coordinator, independent task records, and failures block only dependent work.
